# Security Policy

## Supported Versions
| Version | Supported |
|---|---|
| 0.1.x | Yes |

## Reporting a Vulnerability
If you discover a security vulnerability within RepoGPT:
1. Please do **NOT** open a public issue.
2. Email the maintainers directly at `security@repogpt.local` or contact the UPES Major Project team:
   - Harsh Sinha (SAP 500120229)
   - Anshuman Patel (SAP 500122770)
3. Include details of the vulnerability, reproduction steps, and potential threat impact.
4. We aim to acknowledge receipt within 48 hours and provide patches within 7 days.
